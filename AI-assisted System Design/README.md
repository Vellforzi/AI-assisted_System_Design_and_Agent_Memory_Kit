# AI-assisted System Design

Version: v3.5.0

AI-assisted System Design is the methodology part of the package. It explains how to shape a project so AI assistants can help without becoming an ungrounded source of project truth.

Use this folder when you need to design or repair the operating model of a project:

- what the project is;
- where source-of-truth files live;
- how workstreams are separated;
- how decisions are recorded;
- how AI should reason about missing context;
- how the owner keeps final authority.

Start with:

- `AI-assisted System Design.md`

For memory-specific implementation, use the sibling `Agent Kit/` folder.

## Recommended use

For an existing software project, do not begin by asking an agent to rewrite everything. Begin by creating a Project Map, then connect it to a small repository instruction file. Let the agent answer, audit, and plan from evidence before allowing mutating work.
