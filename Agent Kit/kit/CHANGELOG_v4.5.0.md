# Agent Memory Kit v4.5.0

Source date: 2026-10-27. Previous release: v4.4.0.

## Compact optional skill library

The package now distributes twelve reusable skill families: production engineering,
technical communication, bounded coupled work, long-task recovery, strict task
closure, model/effort selection, hook authoring, subagent authoring, MQL event
lifecycle, bounded Cursor worker contracts, rule authoring and skill authoring.

The reduced entrypoints retain mandatory references, authority boundaries,
preserved-behavior requirements and evidence limits. Templates, recovery helpers,
the prompt compiler and invocation metadata travel with the entrypoints. Ordinary
continuity stays the default; strict proof retains its explicit escalation triggers.

Codex and Cursor job-combat-orchestrator variants are separately preserved in an
OPTION_PROFIT profile, including its recorded discrepancies and project toolchain
reference. These project-specific snapshots are not universal defaults or evidence
that the named hooks and tools are active on another machine.

## Adoption and verification

Read [the skill library guide](SKILL_LIBRARY.md) for client discovery, dependencies,
mirror ownership and deliberate adoption. The skill inventory records transferred
source identities, portable adaptations and payload hashes. The library checker
validates payloads, local links, dependencies and mirrors and can execute the
unchanged recovery and prompt-compiler suites plus its own negative checks.

The five-file portable core installer, current hooks, existing agents and model
settings are unchanged. No automatic skill activation or model switch is added.
The memory module keeps its independent version and historical publication data.

The release archive is generated from the exact release commit. The reference
library checksum list is refreshed from Git contents; unrelated working-tree
edits are excluded. The ZIP and companion SHA-256 file cover the complete source
tree, including both authored layers, licenses and attribution.

Source, packaging and helper tests do not establish instruction adherence in a
model, activation in an already-open client or an adopting project's runtime
correctness. See [the transfer review](SKILL_TRANSFER_REVIEW.md) for the preservation
map. A version file alone does not prove tag or GitHub Release publication.
