# `.work/<change-id>` change folder

Use this reusable folder only for work that needs resumable, multi-step
coordination. Routine, single-session routine-risk work should stay
artifact-light unless its selected workflow profile or risk calls for more.

Required files:

- `PLAN.md`
- `TASKS.md`
- `ACCEPTANCE.md`
- `DEVIATIONS.md`

`artifacts/` is optional. Create it only for useful agent-produced material.

`TASKS.md` is the only authority for operational task status, blockers, and
recorded verification state. All other files and all Kit artifacts may link to
task IDs, but must not duplicate a task-status register.
