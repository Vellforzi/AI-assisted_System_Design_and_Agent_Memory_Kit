# Optional agent artifacts

Create this directory only when an agent-produced artifact materially helps
execution, review, or recovery (for example, a bounded research note, tool
output capture, or disposable analysis). Link each artifact to its source,
date, and related task ID.

Artifacts are supporting evidence, not a task-status authority and not durable
documentation. Promote a durable fact through reviewed `docs/` or
`specs/active/` content. Do not treat an artifact as a substitute for current
runtime evidence or current requirements.
