# /handoff

Purpose: create a clean-slate transfer packet for a fresh chat/session.

Mode: handoff
Default mutations: forbidden

The handoff must let a new session continue without relying on old chat history.

Required sections:

- project/task identity;
- current state;
- completed work;
- confirmed evidence;
- changed files;
- decisions;
- risks/blockers;
- missing evidence;
- next safe step;
- forbidden assumptions;
- Project Map delta proposal;
- Eval trigger yes/no.

Do not include hidden chain-of-thought. Do not use platform summary as evidence.
