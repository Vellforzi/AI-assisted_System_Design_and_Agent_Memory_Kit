# /inventory

Purpose: create a read-only inventory of a project or component before adopting Agent Memory Kit.

Mode: read-only audit
Mutations: forbidden

Output:

- components found;
- likely entrypoints;
- docs found;
- source-authority candidates;
- unknowns;
- risks;
- recommended initial Project Map files;
- next safe step.

Do not modify files, create memory, infer architecture beyond evidence, or read unrelated areas.
