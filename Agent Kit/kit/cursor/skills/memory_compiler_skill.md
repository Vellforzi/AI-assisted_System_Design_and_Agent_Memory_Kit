# Memory Compiler Skill

Purpose: turn approved notes, handoffs, checkpoints, diffs, and owner statements into Project Map memory candidates.

Use when:

- the owner asks to update memory;
- `/map-apply` is invoked;
- a handoff contains proposed Project Map deltas;
- repeated facts or decisions should become durable memory.

Procedure:

1. Identify candidate units: fact, decision, constraint, risk, open question, stale fact, research output, side-effect receipt.
2. Attach evidence and provenance.
3. Assign lifecycle fields: confidence, review_state, last_verified_at, authority_rank, supersedes/superseded_by when needed.
4. Separate verified facts from owner opinions, research output, and inferences.
5. Propose or apply only within explicit mode and scope.

Never convert platform summary into durable memory without owner approval and evidence.
