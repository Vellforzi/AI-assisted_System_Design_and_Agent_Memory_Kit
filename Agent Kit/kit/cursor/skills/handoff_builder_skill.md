# Handoff Builder Skill

Purpose: make the next chat independent of the previous chat.

A good handoff must contain enough evidence and refs for replay, but not a long narrative summary.

Include:

- task identity;
- current state;
- exact completed work;
- exact unfinished work;
- files changed/read;
- tests/checks run;
- decisions and rationale summary;
- risks/open questions;
- next safe step;
- forbidden assumptions;
- Project Map delta proposal.

Do not include hidden chain-of-thought. Do not rely on platform summary.
