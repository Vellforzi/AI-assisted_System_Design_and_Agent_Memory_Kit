# Context Recovery Skill

Purpose: recover safely when chat context may have been summarized, truncated, or polluted.

Procedure:

1. State that platform summary is non-authoritative.
2. Load Project Map current state.
3. Load Working State.
4. Load Source Authority.
5. Load active task/checkpoint/handoff.
6. Retrieve only policy-allowed memory units.
7. Identify confirmed state and missing evidence.
8. Continue only if safe; otherwise stop and ask for missing refs.

Do not reconstruct project facts from chat recall.
