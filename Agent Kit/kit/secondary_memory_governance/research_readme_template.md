## Role

Research files are evidence and context. They do not directly change project
facts, product behavior, runtime behavior, or Project Map truth without reviewed
promotion through source authority.

## Classification

- `external_current_info` - time-sensitive facts that require current sources.
- `domain_background` - non-authoritative background.
- `decision_evidence` - evidence attached to an explicit decision.
- `rejected_or_superseded` - retained only for audit context.

## Promotion Rule

Promote research into project facts only when evidence, freshness, owner
approval, and source-authority classification are recorded.
