The input is the already-approved reduced skills, not the earlier long versions
or unapproved proposals for further reduction. `skills/library.json` records each
input hash, delivered hash and every portable adaptation. Unchanged support files
are delivered with the revised entrypoint so delegated requirements stay reachable.
