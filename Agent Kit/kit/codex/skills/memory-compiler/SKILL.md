# Memory Compiler Skill

Use this skill when the owner provides a handoff, checkpoint, notes, or a Project Map delta and asks to convert it into structured memory.

## Rules

- Do not invent project facts.
- Preserve evidence references.
- Separate current facts, stale facts, decisions, constraints, risks, and open questions.
- External research does not become project truth automatically.
- In answer/analyze/plan mode, output a proposed delta only.
- Apply changes only in explicit `/map-apply` mode.

## Output

```text
Proposed memory units:
- facts_current:
- decisions:
- constraints:
- risks:
- open_questions:
- stale_or_conflicting:
Missing evidence:
Owner approval needed:
```
