# Context Recovery Skill

Use this skill when context compaction, truncation, summary contamination, or thread confusion may have occurred.

## Recovery algorithm

1. Stop relying on chat recall.
2. Load Project Map current state.
3. Load Working State.
4. Load Source Authority.
5. Load active task contract.
6. Check side-effect receipts.
7. Retrieve only policy-allowed memory units.
8. Report missing evidence instead of reconstructing from summary.

## Output

```text
Recovery status:
Trusted sources loaded:
Untrusted summary ignored:
Missing evidence:
Safe next step:
```
