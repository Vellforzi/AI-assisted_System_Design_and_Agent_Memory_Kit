# Handoff Builder Skill

Use this skill when the owner wants to continue work in a fresh session or different agent surface.

## Handoff must include

- task goal;
- current status;
- exact scope;
- confirmed facts;
- decisions and evidence;
- changed files;
- tests or checks;
- blockers;
- next safe step;
- Project Map delta proposal;
- what must not be treated as project truth.

A handoff is not a chat summary. It is a structured replay package.
