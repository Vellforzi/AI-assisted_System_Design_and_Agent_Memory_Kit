# Agent Memory Kit v4.0.0 Changelog

Release date: 2026-08-13

Previous published tag: `v3.12.1`. This is a major because the operating
protocol now states where durable truth lives. Folder names are a
recommendation, not the definition.

This file is release metadata, not publication proof. Publication requires a
matching repository commit, annotated tag, archive checksum, and release
receipt.

Eval suite id: `AMK-EVAL-v4.0.0`.

## Why this release exists

The 3.x line already had the live contour: motive, capability management,
gates, oracles, execution runtime, orchestration choice. GitHub-facing
README and several starter files still read like mid-3.9. The durable-truth
rule was implied by `source_authority` rank order and never said in the
words an agent must repeat.

v4.0.0 jumps the number so the published instrument matches how it actually
works. It does not merge the diverged `new_version` branch. It does not
demote Project Map to secondary navigation.
