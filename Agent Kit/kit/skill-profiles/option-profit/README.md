# OPTION_PROFIT skill profile

These are preserved project-specific sources, reviewed as of 2026-10-27, not
universal Agent Kit defaults. They are not installed by the portable core.

- `codex/job-combat-orchestrator/` is the compact Codex variant.
- `cursor/job-combat-orchestrator/` contains the distinct Cursor entrypoint and
  all three required references. Do not replace one variant with the other.
- `references/option-profit-toolchains.md` preserves the project's concrete
  language/version/check routing separately from portable engineering rules.

The orchestration source files are byte-identical to the approved installed
variants. Their named project policies, helpers, roles, model restrictions,
hooks and local Windows paths require reconciliation against the actual adopting
project and target client. This profile does not distribute or enable those
controls. A path or hook mentioned in prose does not establish that it exists,
is enabled, or successfully enforced the rule in an open session.

In particular, the Cursor references retain their explicit contradictions and
runtime caveats. Preserve those qualifications rather than silently converting
a dated statement into a guarantee. Current owner authority and verified project
policy govern conflicts. Never bypass a real permission or competing-writer
boundary, and never add a duplicate approval merely from historical workflow text.

For generic work use the optional library's bounded-task, engineering,
communication and recovery skills. Adopting these project profiles requires
project-specific review; it is not implied by copying Agent Kit.
