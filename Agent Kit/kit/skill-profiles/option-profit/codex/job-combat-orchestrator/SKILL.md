# OPTION_PROFIT direct orchestrator

The current owner request defines the outcome; current source/tool output is
evidence. Follow project policy for dynamic causal scope. Legacy Workflow V2
profiles, exact scopes, admission and leases are advisory only where current
policy says so; never restore them as mandatory local permissions.
Before current MetaTrader code fixes, apply the task-class policy named in AGENTS.md.

For ordinary multi-file/component programming, use $bounded-coupled-task:
one vertical slice, early executable feedback, preserved independent evidence
and one post-green review.

Before strict escalation, read $outcome-driven-task-closure and apply it only
under its activation conditions. If unavailable, report the gap; do not invent triggers.

Work solo by default; use bounded specialists only for concrete capability or
material latency gain. One writer owns overlapping files. Parent Codex verifies
the diff and evidence and owns the verdict. Git, deploy, credentials, DB writes,
Project Map writes, hosting and MT5 remain separately authority-bound.
