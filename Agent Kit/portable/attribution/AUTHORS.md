# Authors and layers

This repository holds two coordinated layers in one package. **Authorship follows the layer, not the last commit and not who owns the GitHub repository.**

| Layer | Path | Author |
|---|---|---|
| AI-assisted System Design | `AI-assisted System Design/` | [Alexander Lozovoy](https://github.com/All-fatherOdin) (All-fatherOdin) |
| Agent Memory Kit | `Agent Kit/` | [Vellforzi](https://github.com/Vellforzi) |

The GitHub repository and `main` belong to Vellforzi. Edits on `main` do not reassign authorship. If one author edits files in the other author's layer, the layer still belongs to the original author.

## Friend's additional line of work

Alexander Lozovoy maintains a separate branch, [`new_version`](https://github.com/Vellforzi/AI-assisted_System_Design_and_Agent_Memory_Kit/tree/new_version), with adoption profiles, secondary-memory overlay, Context Contract V1, v5-style artifact schemas, and optional integrations. That branch is **not merged into `main`**. Compare: [`main...new_version`](https://github.com/Vellforzi/AI-assisted_System_Design_and_Agent_Memory_Kit/compare/main...new_version).

## Rule in one sentence

Use the folder path to know who authored the instrument; use Project Map and the kit's gates to know what counts as project truth inside an adopting project.
